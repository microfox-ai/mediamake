A fake coding interview just cost Binance $6.3B. In June, an engineer installed a tampered developer tool he found through a search engine. In September, fake recruiters gave a second engineer a take-home test that was really malware. From there, attackers sat inside for about five months. Then, on October 29, they drained 233M XRP in roughly 4 minutes. Binance says about $2.85B is frozen, and it will cover every customer. If you write code: never run a take-home test on your work machine, and install dev tools only from official sources.
