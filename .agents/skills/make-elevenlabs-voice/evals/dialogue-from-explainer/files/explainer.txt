Microsoft Threat Intelligence reported on 5 November 2026 that attackers are running an agentic AI framework called ARTEX across public GitHub to find exposed credentials and API keys. In one case an agent went from searching GitHub for client secrets to taking data out of Azure Key Vault in five minutes. Deleting the commit does not help: a leaked secret works until it is revoked or rotated. GitGuardian found that more than 64% of valid secrets leaked on public GitHub in 2022 still worked when retested in January 2026. What to do: treat every secret that was ever public as compromised and rotate it, turn on push protection, and move apps to managed identities.
