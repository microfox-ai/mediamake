Leaked a secret on GitHub? AI agents now find it for attackers. Microsoft says one agent went from a GitHub search to data out of Azure Key Vault in five minutes. Deleting the commit doesn't fix it: a leaked key works until it's revoked or rotated. GitGuardian found that more than 64% of valid secrets leaked in 2022 still worked in January 2026. So rotate every key that was ever public, turn on push protection, and move apps to managed identities.
