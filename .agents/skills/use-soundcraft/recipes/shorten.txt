# Replace <SONG>, <TRACK> (the file's name without its extension), <CUT_FROM> and <CUT_TO> (seconds; cut
# on a downbeat, at the same place in the bar on both sides), <XF_FROM> and <XF_TO> (30 ms each side of
# <CUT_FROM>). Then:
#   soundcraft-cli script shorten.txt --bounce "<out>.wav" --start 0 --end <the song's length minus the cut>
# Set sample_rate to the song's own (soundcraft-cli info "<SONG>"), so nothing is resampled.
# Check the join: uv run scripts/measure.py join "<out>.wav" <CUT_FROM>
