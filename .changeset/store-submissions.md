mm-use submits to the store. `submit_item` sends a skill, MCP or app the member built, privately, for an admin to review, with the finished production that was made with it; `my_submissions` shows where each stands (waiting, changes asked, accepted with the membership it earned, live, declined) and `withdraw_submission` takes one back before a decision.
